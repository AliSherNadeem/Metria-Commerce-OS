# Metria Commerce OS

Metria Commerce OS is a polished commerce intelligence dashboard for understanding revenue, markets, customers, products, orders, payments, and AI-led opportunities in one workspace.

## Features

- Commerce command center with decision-focused summaries
- Market intelligence and geographic performance views
- Revenue forecasting and opportunity planning
- Product, order, and customer management tables
- Payments, payouts, analytics, and retention insights
- Light and dark themes with responsive layouts
- Animated charts and interactive dashboard controls

## Getting started

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run start    # Run the production build
npm run lint     # Run ESLint
```

## Tech stack

Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Project status

This is a front-end product prototype using representative commerce data. Connect your preferred data services and authentication provider before using it in production.
